What you get How to get started
In a nutshell

This kit helps you change the behavior of an open-weight AI model, one whose files you can download. It offers two paths: reduce false refusals of harmless requests, or teach the model a new behavior, such as asking for the details it needs before making a promise. It’s for people who use these models and want proof that a change worked. You’ll need a powerful computer, or a powerful computer rented online, which costs money for as long as it’s running. The kit hasn’t been run on a model yet, so your first use is a test.

The benefits

Two adjustments you can test

Better prompts can solve a lot. When the same problem keeps coming back, you can change a copy of the model and check whether it was worth it.

🔓 Path 1: remove false restrictions

The problem: The AI sees a strong word and shuts down. It refuses “how to kill a process on a computer” or a history question for a school assignment.

The goal: Answer harmless requests with useful content. The kit uses safe examples only.

🧭 Path 2: behavior your way

The problem: Without knowing the price or the policy, the AI makes up a figure and promises it to the customer.

The goal: Ask for the missing details, then give a direct answer with the correct amount once everything is available.

🛟 Original kept safe

The change happens in a copy. The original version stays intact, and the kit checks this at the end.

⚖️ A fair comparison

The original, the original with a strong instruction, and the adjusted copy get the same questions and are evaluated on cases that weren’t used for the adjustment.

💡 Only edit if it’s worth it

The kit first tests a good prompt. If that solves the problem, you save time and leave the model alone.

Where it comes from

The tool is Heretic

Heretic is an open-source project created by Philipp Emanuel Weidmann and contributors. It changes AI models without retraining them from scratch.

🧰 What it already does

It reduces refusals and, with other settings, can reduce flattery, generic text, humor, and overly long answers.

➕ What this kit adds

Examples in Portuguese, both paths ready to use, a comparison with clear approval, and a guide for beginners.

How it works, without the jargon

Think of a mixing board

You don’t replace the band. You find the channel causing trouble and adjust it carefully, listening to make sure the rest of the music still sounds good.

  1. Two sets of examples
    On one side, situations where the model behaves well. On the other, situations showing the behavior you want to change.
  2. Finding the difference
    Heretic compares what happens inside the model in both cases, like looking for the channel causing the noise.
  3. Adjusting the copy
    It changes the numbers in that copy, without fully training a model.
  4. Different levels, two scores
    Like adjusting seasoning, it tries different amounts. One score measures the goal, and the other measures how far the model moved from the original.
  5. Proof with new questions
    You choose a version, and the kit compares it with the original using questions that weren’t part of the adjustment.

☁️ Why it doesn’t work with every AI

You need the model files. ChatGPT, Claude, and other online services don’t provide those files, even through direct access for developers (the API). Services that offer uncensored models provide their version, not yours.

⚠️ What the kit doesn’t promise

It won’t make the AI smarter or more accurate, and editing it could make other answers worse. The refusal adjustment is designed to address mistakes on harmless requests, not to enable dangerous requests.

The full process

From the original model to an approved copy

1. Choose

Pick the open-weight model and the change you want.

2. Check your computer

Check the memory and disk space before downloading.

3. Keep the original safe

The kit records a digital fingerprint: a code that changes if any file changes.

4. Measure the problem

If there isn’t a problem, the process stops here.

5. Try a good prompt

Sometimes, asking better is enough.

6. Run a pilot

A few attempts show whether it’s worth continuing.

7. Run the adjustment

Heretic finds the best level, and you choose a version.

8. Compare everything

The original, the prompt, and the copy, side by side.

9. Review and decide

Check real answers and ask new questions.

Common questions

Before you get started

Do I need to know how to code?

No, but this is an advanced project. The assistant guides you through the steps, and you’ll need to open it, read the plan, and decide what to approve. If the terminal is new to you, take it slowly.

Can I adjust ChatGPT or Claude?

No. This works only with open-weight models whose files you can download. Claude Code is only the assistant helping with the process.

Does this remove all the AI’s safeguards?

That’s not the goal. The kit targets false refusals of harmless requests. Even so, editing can have effects beyond the examples, so comparison and care are essential.

Can I undo the changes?

Yes. The original is kept separate, and you can delete the adjusted copy.

Does it work on Windows?

The commands were written for Linux and Mac, and Windows hasn’t been checked. Ask the assistant to assess your setup before you start.

How much does it cost?

The kit is free. You pay for the assistant account and your computer, or the computer you rent.

What kind of computer do I need?

It depends on the model. As a rough estimate from the kit, an 8 GB model needs around 16 GB of memory and 24 GB of free disk space. A powerful graphics card helps a lot.
